KP Local Testing Tool v2.0 - Phone access enabled
====================================================
start.bat now binds the server to 0.0.0.0 instead of 127.0.0.1, so devices
on the same WiFi network (like your phone) can reach it too.

HOW TO ACCESS FROM YOUR PHONE:
1. Make sure your phone and PC are on the SAME WiFi network.
2. On the PC, open Command Prompt and run: ipconfig
   Look for "IPv4 Address" under your WiFi adapter, e.g. 192.168.1.5
3. Run start.bat as usual.
4. Windows Firewall may show a popup asking to allow Python/uvicorn
   network access - click "Allow access" (at least for Private networks).
5. On your phone's browser, go to: http://192.168.1.5:8000
   (replace with your actual PC IP from step 2)

If it still doesn't load on the phone: check Windows Firewall settings -
sometimes the popup gets dismissed accidentally and you need to manually
allow python.exe / uvicorn through the firewall for Private networks.
